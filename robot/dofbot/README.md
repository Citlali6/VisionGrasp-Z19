原 `deployment_manifest.json` 保留冻结演示文件哈希。候选分支新增展示注入接口后不能再冒充该字节基线；旧安装器继续严格核对。因此复现本页旧演示时先按[快速开始](../../docs/QUICKSTART.md)检出指定提交，新入口使用当前候选源码并按PSPL说明准备。不要将新旧安装路径混写。

固定工位下的单次语音任务执行与实时展示系统。每轮遵循：**唤醒 → 启动口令 → 稳定识别 → 分类播报完成 → 抓取投放 → 等待重新唤醒**。

本模块负责语音状态机、任务门控、图像旁路预览、动作阶段观测、展示窗口与进程管理。检测模型及底层运动能力作为配套虚拟机依赖接入；来源与责任边界见根目录 [第三方说明](../../THIRD_PARTY.md)。本模块不依赖 FPGA 感知链启动，也不声明 FPGA 已控制此机械臂。

## 支持环境与安装

当前版本支持原 DOFBOT SE 配套 **Ubuntu 22.04、ROS 2 Humble、Python 3.10、普通 yahboom 用户**环境。它不是通用 Ubuntu 上从零安装模型、SDK 和 ROS 的脚本。完整依赖路径与已验证源码哈希见 [external_dependencies.json](external_dependencies.json)。

以下是未来在配套VM的冻结提交工作区中使用的命令，本轮收尾未执行安装或程序：

```bash
bash robot/dofbot/install.sh --check
bash robot/dofbot/install.sh
```

安装器只写入应用文件、用户启动脚本和桌面快捷方式，不启动控制、不打开串口或相机、不播放音频，也不调整音量。若现有控制程序、启动入口或展示窗口仍在运行，安装器会拒绝覆盖；需要更新时先等本轮结束，运行停止脚本并关闭展示窗口，再安装。已有目标文件先备份到安装目录内的 `installer-backups/`；未知用户文件、运行记录和校准数据不会被删除。

安装前不必连接全部 USB 设备；缺少设备会给出提示，正式启动仍要求设备就绪。系统程序、模型、ROS 工作区、SDK 和中文播报音频必须已具备。不要对已经验证的虚拟机直接批量升级 Python 或 ROS 依赖。

## 启动与展示

给机械臂上电并登录 Ubuntu 桌面，在 VMware 中将机械臂 USB、语音 USB、Sonix 摄像头和 C-Media 声卡连接到虚拟机，随后执行：

```bash
bash ~/启动垃圾分拣.sh
```

也可双击桌面 **启动垃圾分拣 · 实时展示**。等待就绪，将物块放到已验证的固定拾取位置并移开手，说“你好小亚”，听到“在的”后说“开始垃圾分拣”。下一轮必须重新唤醒，执行期间输入不会排队触发额外任务。

窗口显示实时画面、识别结果、播报文案、动作指令阶段和目标投放类别。**F11** 切换全屏。关闭展示窗口只关闭显示；重复启动会唤起已有窗口，不重复创建控制实例。

```bash
bash ~/启动垃圾分拣.sh status
bash ~/启动垃圾分拣.sh check
bash ~/停止垃圾分拣.sh
```

停止入口在任务执行期间会要求等待本轮结束。物理急停应使用设备供电断开方式。保持既有相机位置、机械结构和拾取位置；系统当前使用固定工位动作，不提供任意位置抓取。

安装位置保持兼容：`/home/yahboom/codex_voice_sorting_20261029`。记录在该目录的 `records/`，实时图像旁路位于用户运行时目录。启动器不会改动设备参数或原始运动源码。当前现场演示声卡音量为 **75%**，安装器不覆盖用户音量设置。

## 代码与验证

| 部分 | 作用 |
|---|---|
| `pspl_client.py` / `pspl_entry.py` | 当前可选PS/PL任务接入，双端策略/会话/语音边界核对，沿用分类播报后固定工位动作 |
| `pspl_display.py` | 新入口的隔离状态、识别图片和事件记录；复用只读展示，不打开VM相机 |
| `standalone_voice.py` | 单轮状态机、唤醒时效、忙碌输入隔离、播报完成门控 |
| `standalone_runtime.py` | 连接指定检测/动作依赖，限制串口写入阶段，管理唯一相机 |
| `voice_bridge.py` | 纯语音帧解析及类别/音频映射，无 APP 控制器 |
| `preview_publisher.py` | 旁路实时图像、代际标识、真实指令阶段观测 |
| `dashboard*.py` | 只读界面、过期画面识别、单窗口激活 |
| `launch_controller.py` / `ensure_kinematics.py` | 设备预检、单实例、后台启动及纯逆解服务就绪检测 |

现用运行文件的历史字节基线由 [deployment_manifest.json](deployment_manifest.json) 固定；该记录不因新增候选源码而改写。协议提取的历史AST哈希与原UI/运行结果仍归原版本，当前新增接口只按源码审阅呈现。分类模型/底层SDK不作为团队自训/自研成果。

语音模块输出命令编号，界面不是麦克风逐字转写。播报文案来自对应语音资源表；动作阶段依据实际下发的指令，不能替代物理抓取成功传感器。成功回调、界面同步和现场实物效果分别记录，见 [验证说明](../../docs/VALIDATION.md)。

离线测试使用根目录的测试入口，不连接硬件。安装器也可在普通电脑进行隔离演练：

```bash
python robot/dofbot/install.py --staging-root /tmp/dofbot-install-review
```

该模式仅在指定目录内创建模拟用户目录和安装文件，不检查或修改实际 Ubuntu 会话，不执行任何运行脚本。生成的包仍面向配套 Linux 虚拟机；它不代表已经完成新的实机安装验收。
