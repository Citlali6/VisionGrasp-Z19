# 芯语智分：让分类成为一次可参与的操作

**面向固废源头分类的语音—视觉—执行一体化工作站**

垃圾分类的最后一公里，从来不是缺标准，而是缺反馈。

一个人把瓶子丢进错误的桶，没人纠正；丢对了，也没有回应。分类知识停留在标语和手册里，运营者每天看到的是清运量，而不是分类质量。芯语智分想补上的，就是这一小段“回应”。

它把语音指令、Zynq PS/PL 视觉判断、候选决策和机械执行组织成一个固定工位：使用者发起任务，系统识别目标、播报类别，机械臂完成投放，界面同步呈现过程。一次任务，一条完整链路。

**听见指令，看清目标，让分类落到行动。**

## 为什么是现在

- 分类标准越来越细，前端判断却仍靠人记。
- 语音、视觉与机械执行的成本在下降，一套完整链路可以放进一个桌面工位。
- 运营方需要的不只是设备，而是可复制、可观察、可计量的节点。

## 三层场景

### L1 单点：把一台工位做扎实

校园绿色课堂、社区低碳体验台。一次唤醒对应一次任务：参与者放入样本、发出指令，观察识别、播报、投放和复位。运营者可以围绕同一条过程讲解分类依据，也可以让下一位参与者重新开始。

这一层已经交付：固定工位分拣应用、Z19 感知链和完整的过程记录。

### L2 节点：把工位复制到人流入口

写字楼大堂、园区食堂、赛事与展馆。短时、高频、单人操作；同一套任务协议、候选规则和界面可以复制到不同点位，只替换样本、模型、容器和固定拾取位置。

这一层的关键不是再做一台机器，而是让同一套接口在不同点位复用。

### L3 网络：让节点产生数据

多节点回传分类结果、失败原因和任务量，形成运营看板和碳减排计量。当前项目提供任务与感知接口，网络层属于后续路线。

## 产品价值

| 对象 | 价值 |
|---|---|
| 参与者 | 一句口令完成一次分类，得到即时反馈 |
| 运营者 | 单件任务、过程可见、可复制，降低讲解与维护负担 |
| 开发者 | 同一任务贯穿 PL 算子、PS 模型、接口与执行 |
| 研究者 | PS/PL 分工、候选门控、只读观测的可复用样本 |

## 从识别标签到完整交互

在展台或课堂里，组织者需要让参与者知道何时开始、机器识别了什么、接下来会发生什么，以及这一轮何时结束。只有识别标签，很难把这些环节连起来；相机、模型、语音和机械臂各自运行，也会增加演示与讲解的负担。

工作站以单次任务组织交互。参与者放置样本，发出唤醒和启动口令，观察类别反馈与投放动作，完成后让出工位。教师或工作人员可以围绕这条清楚的过程讲解分类依据，也可以引导参与者比较自己的判断与系统结果。

对开发者，这个任务提供了共同的应用背景：视频处理得到什么数据，模型怎样解释目标，候选规则接受什么条件，语音怎样改变任务状态，执行过程又怎样反映到界面。软件与硬件因此有一条可以逐层追踪的数据路径。

## 一次任务怎样完成

系统中的语音助手昵称为“小亚”，使用“你好小亚”唤醒。固定工位分拣按以下顺序工作：

| 阶段 | 使用者或系统的操作 | 可观察的反馈 |
|---|---|---|
| 准备样本 | 使用者将支持的样本放到固定拾取位置并移开手 | 工位画面 |
| 唤醒与启动 | 使用者说“你好小亚”，等待“在的”，再说“开始垃圾分拣” | 唤醒回应、语音事件和任务状态 |
| 观察与识别 | 系统准备观察姿态，接受稳定出现的目标 | 实时画面、物品名称与投放类别 |
| 分类播报 | 系统播放对应物品与类别音频 | 播报声音和界面文案 |
| 抓取投放 | 播报完成后，SDK 执行既有类别动作 | 已下发动作的抓取、转运、释放和返回阶段 |
| 本轮结束 | 系统回到等待唤醒 | 下一轮从新唤醒开始 |

忙碌期间输入的命令不会积压为下一轮动作。未找到稳定目标时本轮结束；分类播报失败时不进入抓取。窗口从控制进程共享画面和状态，动作阶段表示指令进度，实际夹持和投放由操作者观察。

设备连接、启动与停止操作见[快速开始](QUICKSTART.md)。

## 技术怎样服务这条流程

**语音提出任务，视觉提供目标，候选规则约束执行，任务软件组织动作，界面呈现过程。**

固定工位分拣由上位机中的相机、检测模型、串口语音模块与 DOFBOT SDK 完成。开发者可以从[机械臂应用](../robot/dofbot/README.md)阅读状态机、播报完成门控、输入隔离、共享预览和进程管理。

Z19 PS/PL 四功能集成工程提供另一套感知与接口配置：PS 负责图像和 PCM 采集、CPU 模型、坐标解释、Vosk 及任务通信；PL 提供 RGB 校正、HSV/掩码、ROI/包围框/一阶矩、DC/FIR/可选软门和候选规则；可选上位机客户端沿用既有任务与 SDK 动作。源码连接见 [system_pspl](../fpga/system_pspl/README.md)。

候选策略默认使用 `semantic_bbox`，依据同帧语义检测框的区域、面积和连续帧条件；需要指定颜色的工位可显式选择 `color_association`。像素坐标、颜色质心和相机标定后的平面坐标各有明确含义，机械臂采用固定拾取动作。

## 选择适合的工程入口

固定工位分拣适合体验完整交互；独立 Z19 颜色/语音/网格模块适合阅读板端感知与坐标展示；四功能 PS/PL 集成工程提供源码、构建入口与 bit/XSA。三者的环境、镜像、依赖与版本统一见[配置与部署](CONFIGURATIONS.md)，各自结果见[验证记录](VALIDATION.md)。
