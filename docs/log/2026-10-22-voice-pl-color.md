# 2026-10-22：语音颜色选择与真实 PL 定位

在板端 ARM 上使用现有 Vosk 中文小模型和 ALSA 采音，根据明确颜色关键词产生带请求号/时间戳的颜色请求。PL 继续计算 HSV、掩码、像素计数与包围框，保持原颜色固件。

颜色词使用模型词表核验的动态语法及置信度过滤。否定、多颜色歧义和低置信度不生成新请求；结果必须来自请求后采集且请求号匹配的新帧。零匹配、过期、断流和编号不符隐藏旧坐标。

## 现场证据

- 用户确认“已经自动定位红色”。语音来源请求 `8312515278`、文本“红色”、颜色 1；USB/PL 帧号均为 `20456`，框 `[405,108,508,196]`，匹配 4,377 像素，约 5.93 fps。
- 后续真实状态记录“拿取 绿色 物品”，请求 `8531050836`、颜色 2；USB/PL 帧号均为 `26393`，框 `[225,231,352,359]`，匹配 11,938 像素，约 5.89 fps。
- 识别“不要 拿 红色 物品”时 `accepted=false`，没有覆盖绿色请求。

记录来自现场语音与实际 PL 帧；否定、多颜色歧义与低置信度不生成新请求。

Python 3.7 语法、板端 GCC 构建及语音环境入口已检查。复现入口见 [VOICE](../../fpga/color_locator/VOICE.md)。
