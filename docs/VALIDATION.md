# 验证结果

本页按证据类型记录结果：**板端现场**、**软件检查**、**RTL 仿真**、**综合与实现**。每项结果对应其配置与版本；数值、条件与来源统一在[证据矩阵](competition/EVIDENCE_MATRIX.md)维护。

## 四功能集成工程构建结果（2026-10-31）

`z19-pspl-four-functions-v1` 在 Vivado 2020.1 下完成综合、实现与 bitstream 生成，顶层 `system_pspl_wrapper`，器件 `xczu19eg-ffvc1760-2-i`，`ps0/pl_clk1` 目标 100 MHz。

| 指标 | 结果 |
|---|---|
| WNS / WHS | +0.632 ns / +0.010 ns |
| 失败端点 | 0 / 27,352 |
| 估算 Fmax | ≈ 106.7 MHz |
| CLB LUT / 寄存器 | 7,292（1.40%）/ 8,882（0.85%） |
| DSP / BRAM | 14（0.71%）/ 0 |
| DRC | 52 Warning，0 Critical，0 Error |
| 片上功耗（vectorless 估算） | 4.167 W |

原始报告、XSA 与逐文件哈希见[构建记录](../deliverables/fpga_build_20261031/README.md)。52 条 DRC Warning 属于 DSP 输入/输出流水建议和 1 条无负载信号，不影响实现与 bitstream 生成。

## DOFBOT 定稿版

原部署版本通过四组 **65 项离线检查**：语音状态机 20 项、启动管理 21 项、预览旁路 15 项、展示模型 9 项。覆盖单次唤醒、有效期、忙碌输入隔离、分类播报后抓取投放、超时退出、重复启动及陈旧画面拒绝。发布复验在原 65 项之外新增 4 项协议等价检查及 9 项安装打包检查，合计 **78 项通过**；并通过三份安装/启动 Shell 脚本语法检查。

| 验证项 | 已观察结果 | 证据范围 |
|---|---|---|
| 单轮任务 | 一次唤醒与启动口令执行一次，结束回到等待唤醒 | 状态机测试与现场用户验收 |
| 初次/重复启动 | 就绪等待期间无新动作；重复启动保持一个控制实例和一个展示窗口 | 进程身份、运行记录与启动检查 |
| 摄像头及界面 | 摄像头只由运行进程持有；帧序号持续前进，界面同步展示识别、播报与阶段 | 运行记录、[真实截图](assets/dashboard.png)和现场反馈 |
| 动作调用顺序 | 四个分类分支的观测包装保持原 SDK 调用序列 | 基于真实依赖源码的离线替身检查 |
| 实物效果 | 展示启用后的记录含 3 次抓取回调，另有一次识别超时 | 回调代表软件执行过程；夹持与投放由现场观察确认 |
| 声音配置 | 当前演示使用 USB 声卡 75% 音量 | 已验证配置；安装器不修改音量 |

当前为固定工位、单物块演示。没有深度相机，系统按单件任务组织交互，不声称任意空间动态定位、碰撞规划或外部计量精度。源码版本和外部依赖通过[部署清单](../robot/dofbot/deployment_manifest.json)与[依赖清单](../robot/dofbot/external_dependencies.json)追溯。

## 发布离线检查

机械臂 78 项、音频采集/PCM 10 项、SD 格式 9 项，共 **97 项 Python 检查通过**。另通过 12 个 PowerShell 模拟磁盘守卫场景、当前音频依赖离线打包及清单核验；这些步骤不连接硬件。复现命令见[开发指南](DEVELOPMENT.md)，CI 在 Linux 和 Windows 运行适用软件检查。

## Z19 颜色、语音与网格

三套颜色模块在 Vivado 2020.1 下复跑通过，均退出 0 且出现对应成功标记：

| 检查 | 覆盖范围 | 结果 |
|---|---|---|
| HSV 数值 | 1,024 组 RGB 向量、数值容差、有效间隙与 TLAST | `HSV_PASS` |
| 视频流 | 2,064 个数据拍、背压、SOF/EOL、复位和帧内配置快照 | `COLOR_AXIS_PASS` |
| AXI-Lite | 64 像素、四种颜色配置、AW/W 解耦、读取停顿、统计与错误恢复 | `COLOR_AXI_PASS` |

板端记录证明 ARM 识别颜色词、PL 执行 HSV/掩码/像素统计/全局框，浏览器计算实体网格与坐标，板端合成并播放坐标语音。balanced 模式保持 **1280×720 原始视野**，PL 处理 **640×360**：一次实测板端平均发布 7.26 fps、浏览器约 7.2 fps、采集至发布约 187 ms；该数字属于 balanced 配置。语音合成并发时曾短暂降帧。

网格尺寸来自用户确认的 40×30 cm 板面。至少 5 个未参与拟合的图内交点用于检查，阈值为平均 3 mm、最大 6 mm；这些是图内检查残差，不是独立外部尺量精度。相同颜色的多个目标合并为全局包围框。

详细记录：[颜色上板](log/2026-10-22-pl-color.md)、[颜色语音](log/2026-10-22-voice-pl-color.md)、[网格与帧率](log/2026-10-23-grid-preview.md)、[坐标播报](log/2026-10-23-coordinate-speech.md)。

## MIPI 相机与基础环境

独立 MIPI 相机链保留原工程和已验证产物。历史 1920×1080 采集记录为 757 帧 / 30.047 秒，接收测量约 25.16 fps；另有 600 秒持续采集检查及故障检测记录，见[相机证据](fpga/evidence/2026-10-10/README.md)。相机固件与颜色固件是不同硬件配置，分别维护地址与镜像。

相机源码按其原始 Vivado 2020.2_AR75986 要求维护，不在 2020.1 强制升级 IP。SD 基础工具的离线测试验证镜像格式与准备步骤。

## 候选目标门控工程

门控的接口、软件回放、RTL 仿真和综合分别验证。旧颜色链结果与新门控分别记录；颜色 bit 与现用部署保持原版本。

新增软件适配、元数据校验、寄存器模型与回放共 94 项离线检查通过，合成回放示例在基线帧 10 后提交 11/12/13 并消费一次许可。当前 pytest 总计 172 项，另有音频 10 项和 SD 格式 9 项，共 191 项 Python 检查。

RTL 仿真输出 `SORT_GUARD_PASS checks=661 axi_writes=418 axi_reads=66 axi_permits=2 core_permits=1 timeout_priority=PASS reset=PASS`。661 是测试平台断言检查次数，包含事务与背压检查。代表场景包括配置快照、ROI/匹配像素数、固定锚点抖动、序号回绕、重复/倒序、超时边界、忙碌取消、external_busy 外部输入跨复位保持、单次消费及 AXI 错误处理；最终报告见门控模块。

独立 OOC 综合已通过：Vivado 2020.1，器件 `xczu19eg-ffvc1760-2-i`，综合后施加 10 ns 的报告时钟约束，结果为 866 LUT、949 FF、0 BRAM、0 DSP。综合网表时序为 WNS 7.112 ns、WHS 0.061 ns；67 个输入、40 个输出没有 I/O delay，`HD.CLK_SRC` 未设置。该结果属于独立综合网表。

完整工具报告与脱敏范围见[门控证据索引](../fpga/sort_guard/validation/README.md)。报告仅移除 Host/临时路径标识，保留技术内容，并同时记录原始与公开副本哈希。
