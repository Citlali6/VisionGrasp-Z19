# 小亚智分：产品定位与已有方案

**小亚智分——基于 Z19 PS/PL 协同设计的语音视觉垃圾分拣工作站**

**听见指令，看清目标，让分类落到行动。**

本作品面向固定桌面工位的分类交互与展示：用户说出唤醒和启动口令，系统识别限定物块、播报类别，再通过机械臂展示投放过程。使用者从同一个界面观察任务阶段，工程学习者从源码理解像素流水、数字滤波、总线事务和任务状态机如何配合。

## 问题与使用对象

单独显示识别标签，难以呈现“发起任务—理解目标—给出反馈—执行动作”的完整体验；把相机、模型、语音和机械臂分别放在多个开发窗口中，也不利于讲解和复现。工作站把这条交互路径组织成一次有边界、可观察的任务。

校园环保课堂、社区科普展台、嵌入式/FPGA 实验教学与创客实践是目标场景，尚无已部署站点或教学效果评估。当前可引用的应用记录来自固定拾取位置的单物块演示；物块材质及真实废弃物覆盖未形成核验清单，因此保持“限定演示物块”的口径。模型中的“有害垃圾”标签不代表具备处理实际危险废弃物的条件。

## 一次任务的体验

1. 说“你好小亚”，等待“在的”。
2. 说“开始垃圾分拣”，系统消耗本次唤醒，进入准备观察姿态。
3. 识别稳定目标并播报物品与类别。
4. 播报完成后执行既有类别抓取投放动作，界面显示动作指令阶段。
5. 本轮结束后重新等待唤醒；忙碌输入不会积压成下一轮动作。

原部署使用 VM 中的模型和外接串口语音模块；新的可选配置由 Z19 PS/PL 提供感知与受限语音事件，VM 继续承担任务编排、播报和 SDK 执行。两者的版本、环境与证据归属统一见[系统工程表](../../fpga/system_pspl/README.md)和[证据矩阵](EVIDENCE_MATRIX.md)。

## 团队形成的工程差异

| 价值 | 可定位的实现 |
|---|---|
| 一次任务清楚结束 | 单次唤醒/启动、忙碌输入隔离、播报完成门控；USB PCM 在任务边界重建采音/滤波/ASR 代际 |
| 数据可对应 | 相机/会话/帧/配置/像素空间身份；原始预览、PL 输出、模型输入与识别图分别记录 |
| PL 有实际计算 | 通道定点校正、HSV/掩码、ROI 一阶矩、DC/FIR/软门、FIFO/背压、AXI 接口与候选状态机 |
| 展示可追溯 | 设备单一所有者、相机旁路、陈旧图像判定、识别图与任务事件、实际 SDK 指令阶段 |
| 开发经验可复用 | [Skill](../../skill/README.md)、[AI 协作案例](../../report/ai_collaboration.md)、版本化工程和来源说明 |

默认候选策略是 `semantic_bbox`：语义目标的检测框面积和稳定性进入 PL 门控，不要求垃圾带有指定颜色。`color_association` 作为显式选用的颜色工位条件。该区分使类别任务与颜色实验各有适用范围。

## 扩展路线与产品边界

近期工作是把已交付的四功能源码与明确目标环境对应，补齐合法模型依赖、新 profile 的板级输出与参考比对。教学使用可以围绕流控、寄存器契约、任务边界和只读展示逐项展开。轻量工位适配属于后续方向，需重新确定物料、夹具、相机标定和独立测量方法。

当前机械臂执行仍是固定工位类别动作。颜色质心、检测框中心和可选桌面毫米坐标分别输出；它们不等于机械臂基座三维抓取姿态。作品的成熟表达来自一致的体验、工程入口和版本证据，当前没有依据填写工业产线或无人值守能力。
