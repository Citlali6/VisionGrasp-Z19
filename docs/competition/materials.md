## 拍摄与记录建议

| 编号 | 材料 | 应记录的信息 |
|---|---|---|
| P01 | 系统正面全局照 | 机械臂、固定工位、相机、主机、语音设备及投放区域 |
| P02 | 斜 45° 全局照 | 相机安装关系、工作空间和设备连接 |
| P03 | Z19 感知台架照 | 板卡、USB 相机、实体网格、音频设备 |
| P04 | 连接近照/连接图 | 电源、USB、串口方向、关键接口标签 |
| P05 | 一次分拣连续记录 | 同一任务的唤醒、识别、播报、抓取和投放；保留原视频与时间 |
| P06 | 分类与抓取测试表 | 每次物品、真实类别、识别结果、是否夹起、是否正确投放、耗时和失败原因 |

每组表记录日期、版本、对象与次数、相机/光照条件、操作者、判定规则和原始证据文件。先定义试验方案，再采样；试验失败和识别超时保留在分母中，变更条件后分组统计。原始记录放团队受控位置，公开仓库仅收录脱敏、精简、可追溯的证据。

## 匿名化

拍摄时保证能看清装置与连接，避免学校名称、个人信息或无关屏幕进入匿名提交材料。安装布置图可以自行绘制；厂商结构图/原理图按合法来源注明，不作为团队新机械或新 PCB 设计。
