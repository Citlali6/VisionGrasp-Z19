# 参赛技术资料入口

建议作品名称：**VisionGrasp-Z19：面向固定工位的 FPGA 辅助感知与语音交互分拣平台**。

本目录供队友撰写技术文档、准备展示和核对事实。章节要求依据用户提供的《技术文档模板(2).docx》提取；这里提供对应资料，不附带模板原件，也不是已经提交的比赛文档。

2026-10-30 补充[四功能 PS/PL 源码工程](../../fpga/system_pspl/README.md)。技术正文使用视频预处理、垃圾识别、视觉定位和音频滤波的实际算法/接口；实现与环境统一看工程表，旧现场/仿真/综合结果继续按证据矩阵引用。新profile没有对应性能测量。

## 按这个顺序使用

1. 阅读[章节提纲与可复用文案](TECHNICAL_OUTLINE.md)，按官方字数要求撰写。
2. 用[设计细节与接口素材](DESIGN_DETAILS.md)展开模块输入/输出与流程，再从[事实、证据与指标表](EVIDENCE_MATRIX.md)选择数字；同时保留条件和证据等级。
3. 按[图表与补采清单](MATERIALS.md)准备正面、45°实物照、连接图和补测数据。
4. 以[架构](../ARCHITECTURE.md)、[验证](../VALIDATION.md)及模块源码为依据，完成技术细节和参考文献。

平台材料同时呈现现用 DOFBOT 实测、原有 Z19 PL 视觉实测、候选目标门控的历史独立工程记录，以及本轮四功能源码。现用演示图和新工程连接图分开使用；各自结果按版本引用。

## 贡献表达

可重点介绍：硬件颜色统计链的流控与接口、候选目标时空约束、单次任务状态机、播报完成门控、忙碌输入隔离、控制/展示解耦、陈旧数据防护与部署管理。

资料中明确区分团队实现、原有硬件/算法基础和外部运行依赖。引用检测模型、SDK、既有运动模块和上游 IP 时，按[第三方说明](../../THIRD_PARTY.md)记录来源；现有机构的照片、连接图可以用于系统说明，不标为自行设计的机械或电路成果。
