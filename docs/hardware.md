# 硬件与运行环境

## DOFBOT 分拣链

| 设备 | 用途 | 已验证标识 |
|---|---|---|
| DOFBOT SE 机械臂 | 固定工位抓取与按类别投放 | 控制 USB `1a86:7523`，别名 `/dev/myserial` |
| 语音识别模块 | 唤醒与命令事件输入 | 语音 USB `1a86:7522`，别名 `/dev/myspeech` |
| Sonix USB 相机 | 实时画面与垃圾识别 | `usb-Sonix_Technology_Co.__Ltd._USB_2.0_Camera-video-index0` |
| C-Media USB 声卡/扬声器 | 唤醒回应与分类播报 | PulseAudio 中对应 USB Audio Device 输出 |
| Ubuntu 桌面虚拟机 | ROS 环境、应用与展示窗口 | Ubuntu 22.04 / ROS 2 Humble / Python 3.10 |

上电后将上述 USB 设备透传到虚拟机。串口别名和摄像头 by-id 避免依赖易变化的 `ttyUSB`、`video` 数字编号；依赖文件与配置需符合[组件检查](../robot/dofbot/README.md)。

维持已验证的相机位置、桌面布局、机械结构和固定拾取位置。无需深度相机；当前程序不根据任意三维目标位置重规划轨迹。桌面窗口复用后台相机数据，不再单独打开设备。

软件启动检查设备占用，初始化阶段不自动发起运动。正常动作由现场的新一组唤醒与启动命令触发。运行时保持人员与杂物离开动作区域，并能直接切断机械臂电源。

## Z19 感知链

| 部分 | 用途 |
|---|---|
| ALINX Z19 / XCZU19EG | PS 传输、语音处理与 PL 颜色感知 |
| USB UVC 相机 | 当前颜色感知链的图像来源 |
| USB 麦克风与扬声器 | PS 侧颜色关键词识别、坐标播报 |
| IMX214/MIPI 相机链 | 独立的板卡相机基础工程与 Linux 高清采集 |

USB 颜色工程与 MIPI 相机工程使用各自匹配的硬件镜像；不能把一套 bit 文件的结果作为另一套工程的验收。当前 Z19 输出用于颜色、坐标与语音展示，不下发 DOFBOT 运动指令。

Z19 工具与镜像说明见 [FPGA 导航](fpga/README.md)。完整厂商系统镜像和 DOFBOT SDK、模型、音频不随本仓库分发；已保留 Z19 交付资产及外部依赖的来源、版本和许可见[第三方说明](../THIRD_PARTY.md)。

## 新增门控工程的硬件接口

`sort_guard` 定义独立 AXI4-Lite 外设，32 位数据、12 位字节地址及同域 busy 输入；许可输出为单周期事件并在寄存器中留存。尚未分配板端物理地址或生成部署位流。现有 Z19 颜色固件和 DOFBOT 设备连接保持原样；后续由 PS 读取颜色统计并转写到新外设，不能复用颜色 IP 地址直接访问它。字段和时钟约定见[接口说明](../fpga/sort_guard/INTERFACE.md)。
