# VisionGrasp-Z19

### 语音视觉垃圾分拣 · FPGA 感知平台

说出指令，让系统完成识别、分类播报与一次抓取投放。VisionGrasp-Z19 将语音交互、视觉任务编排、机械臂执行和实时展示组织为可复现的桌面分拣系统，并提供独立的 Z19 FPGA 颜色感知与坐标展示链路。

## 一次指令，一次完整任务

**“你好小亚” → “在的” → “开始垃圾分拣” → 识别 → 分类播报 → 抓取投放 → 等待重新唤醒。**

- **明确的任务边界**：每次唤醒与启动只执行一轮；任务期间的新语音不排队触发下一轮。
- **可验证的执行顺序**：连续稳定识别后先播报，播报完成才进入抓取投放；识别超时不抓取。
- **独立运行**：虚拟机直接连接摄像头、语音串口与机械臂，无需手机控制。
- **实时可视化**：同一摄像头画面供控制与展示使用，显示当前类别、目标区域、动作阶段和语音记录；F11 可全屏演示。
- **工程化部署**：设备预检、单实例启动、进程身份核验、状态记录和桌面入口集中管理。

当前机械臂版本面向 **已标定的固定拾取工位**，不依赖深度相机。识别到的类别决定投放区域；它不是任意三维位置的动态抓取系统。

## 两条可独立运行的链路

| 模块 | 当前能力 | 入口 |
|---|---|---|
| DOFBOT SE 分拣 | 语音唤醒、单次任务编排、垃圾识别与播报、抓取投放、实时窗口 | [机械臂组件](robot/dofbot/README.md) |
| Z19 FPGA 感知 | PL 颜色阈值、像素统计与包围框，浏览器网格坐标，PS 语音请求与播报 | [FPGA 导航](docs/fpga/README.md) |
| Z19 相机基础 | IMX214/MIPI 配套硬件、Linux 采集驱动和高清预览 | [相机说明](fpga/camera_hw/README.md) |

DOFBOT 当前任务由 Ubuntu 运行时编排。Z19 颜色感知链独立验证，尚未接入这套机械臂的运动控制；两者的处理位置与验证范围见[架构说明](docs/ARCHITECTURE.md)。

## 启动展示

适用环境：已具备配套 SDK、模型、音频和 ROS 2 环境的 Ubuntu 22.04 虚拟机。首次从仓库部署：

```bash
git clone --depth 1 https://github.com/Citlali6/VisionGrasp-Z19.git
cd VisionGrasp-Z19
bash robot/dofbot/install.sh --check
bash robot/dofbot/install.sh
```

安装不会自动启动任务，已有运行实例会阻止覆盖。已安装的虚拟机直接运行：

```bash
bash ~/启动垃圾分拣.sh
```

也可以双击桌面 **“启动垃圾分拣 · 实时展示”**。显示就绪后，将物块放到已验证拾取位置，再说唤醒词和启动口令。关闭窗口只关闭显示；结束后台功能使用 `bash ~/停止垃圾分拣.sh`。

完整依赖、USB 连接和故障排查见[快速开始](docs/QUICKSTART.md)。模型、SDK 和语音素材由外部配套环境提供，不随本仓库分发。
